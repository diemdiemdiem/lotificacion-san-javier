# Lotificación San Javier

Plano interactivo de lotificación de la Reserva San Javier (Irapuato, Gto.) — TRAMORA.

Permite mover calles, cambiar número y frente de lotes, jardín central, corredores y camellón, y ver en vivo el cuadro de áreas, la tabla de lotes y los números del negocio.

Abre `index.html` en el navegador o en la página de GitHub Pages del repositorio.
